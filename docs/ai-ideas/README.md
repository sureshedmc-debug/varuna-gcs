# VARUNA AI — daily idea log

A scheduled agent reads the detection pipeline, searches current research, and
drops one dated batch of ideas in this folder each day.

Each idea is written to be actionable: what to change, **which file and line**,
what gain to expect, and what it costs. Nothing here is implemented until the
ledger below says so — the batches are a backlog, not a changelog.

## How to use it

1. Read the newest dated file.
2. Pick from **Do these first** — they are ordered by (gain ÷ effort).
3. Move the row in the ledger to `doing` / `done` / `rejected` with a one-line reason.

Keeping the ledger current is what stops tomorrow's batch repeating today's.
